# AmateurAlarm
A 4 key alarm clock that is powered by a XIAO ESP32 module, and displayed by a 2.25inch TFT Screen. It has a black screen and red numbers, because that's the amateur tech guy's favorite color scheme!

## What is This?
It is a custom alarm clock powered by a Seeed XIAO ESP32 microcontroller and Arduino Firmware, allowing it to be fully customizable and compact.

Have you ever felt like all you need is a simple, cheap, easy to make alarm clock but, you're simply just irritated from having to click so many buttons and learn so many skills just to make that happen?

Well AmateurAlarm is for you! Cause with AmateurAlarm you can just use the keys in the back to set your alarm whenever you want and the real kicker is that this alarm and it's keys are fully customizeable! so if you're unhappy with what your keys do, just simply hack the firmware and flash it!

## Features:

- 4 key buttons to help set your alarm up
- One buzzer to wake you up!
- Custom PCB to eliminate the need for messy wires
- A 3D printed Case for accessibility and ease
- Custom Arduino Firmware which allows easy reprogramming
